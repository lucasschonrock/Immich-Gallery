API key setup

Use the smallest key that works.

Immich Gallery needs eleven read-oriented permissions for complete browsing, search, slideshow, video, and account functionality. It does not need administrative or library mutation access.

Last verified against demo.immich.app on July 24, 2026.

Required scopes

Complete permission set

album.read
Browse personal and shared albums.
asset.download
Load full-resolution originals in the fullscreen viewer and slideshow.
asset.read
Browse the Timeline, search, filter, load metadata, and retrieve random assets.
asset.statistics
Display library statistics.
asset.view
Load thumbnails, previews, and video playback.
folder.read
Browse external library folders.
person.read
Browse people and person thumbnails.
stack.read
Open stacked photos.
tag.read
Browse tags.
user.read
Validate the key and load the current user.
userProfileImage.read
Display account profile images.

Setup

  1. Open Immich account settings.
  2. Create a new API key.
  3. Select the eleven permissions listed.
  4. Copy the key into Immich Gallery on Apple TV.

Not required

Do not grant create, update, delete, upload, or administrative permissions. The app is a read-only gallery client.

Important details

  • timeline.read is not required. Immich currently protects Timeline browsing with asset.read.
  • map.read and map.search are not required for the app's location search.
  • Locked Folder unlocking requires a password-backed session and cannot be enabled by an API-key permission.
